HOW TO RESTART

日常の続きを、もっと気軽に。

あなたのペースで、セーブして、また始めよう。

01

冒険に名前をつける

ゲーム、読書、イラスト、勉強。どんな日常にも、セーブポイントを。

02

ひと休みの前にセーブ

進んだところ、次の一歩、忘れたくないこと。短いメモを残しておこう。

03

好きなときに、つづきから

しばらく間が空いても大丈夫。前の自分のメモが、続きを教えてくれる。

ABOUT THIS PREVIEW

いま体験できること

これは HTML と CSS で作った画面プレビューです。表示されている記録はサンプルです。

  • セーブ一覧と、進行中・おやすみ中・クリア済みの画面を見る
  • カテゴリで絞り込み、サンプルの「つづきから」を開く
  • 新規登録・編集フォームで入力を試す
  • スマートフォンでもレイアウトを確認する
  • 最近のセーブから続きを確認し、セーブがないときの画面も試す — 初めて使うときの画面を見る

データの保存・更新・削除、アカウント機能は今後追加する予定です。入力内容はページを離れると失われる場合があります。
