## 仍需在本機瀏覽器確認

目前執行環境限制瀏覽器程序啟動，因此沒有宣稱已通過完整的 Chromium 操作或手機實機測試。

在 VS Code 開啟後，建議檢查：

1. 桌機瀏覽器視窗：1440、1024、768px 寬度。
2. 開啟開發者工具的裝置模式：390、320px 寬度。
3. 首頁的分類切換、卡片連結、側邊選單，以及新增和編輯頁的欄位。
4. 用 Tab 鍵移動焦點，用方向鍵切換分類 radio。

静態排版預覽不等同於完整瀏覽器驗證。
