# ReStart 本機 PHP 版設計

日期：2026-10-25。基準：db63131816bea65ccc81ea36bd9fe5767d507960。
分支：feature/php-local-saves，原 main 與靜態版分支保留。

## 目標與已確認範圍
讓使用者在自己的電腦管理遊戲、閱讀、創作、學習與其他活動，關閉瀏覽器或重新開機後，已儲存資料仍存在。
- PHP＋MySQL 相容資料庫；產品不使用 JavaScript，不自動保存草稿。
- 單人、本機使用，無帳號與登入，不發布到外網。
- 新增、查看、修改、刪除；每個活動只保留最新進度，無歷程或回收桶。
- 進行中、暫停中、已完成全部由使用者手動設定，不因閒置時間自動變更。
- 繼續上次：只取進行中活動，依更新時間由新到舊，時間相同以編號由大到小決定。
- 沒有進行中活動時，提供查看暫停活動與新增入口。
- 刪除先顯示該筆標題與確認頁，再以 POST 正式刪除。
- 初始資料為空；示範資料另外以明確的命令選擇匯入。
- 中／日／英介面共用同一批資料；使用者輸入不自動翻譯。
- 附本機設定、啟動、停止、備份與還原說明。

## 曾討論的方案
1. JavaScript＋瀏覽器儲存：設定較少，但需額外學 JavaScript，資料綁定瀏覽器；未採用。
2. PHP＋資料庫：配合學校課程，正式表單送出後保存；使用者已選擇。
3. PHP 正式保存＋JavaScript 草稿保存：曾討論，使用者明確取消草稿與 JavaScript。

## 頁面與資料操作
沿用深色遊戲風格、SVG 圖示、卡片、分類及三語切換。新的入口為 index.php；原 HTML 與備選圖片保留作參考，程式內導覽全部走 PHP 入口。
採單一 PHP 入口與小型共用樣板，view 參數使用白名單：list、new、detail、edit、delete、help。
狀態與分類以 GET 查詢，重新整理或切換語言保留目前頁面、活動編號與有效篩選。新增／編輯中切換語言會離開表單，需顯示未儲存內容不會保留的提示。
列表每頁 12 筆、依更新時間排序；狀態計數代表全部存檔，不隨分類縮減；列表另顯示篩選後數量。
詳細頁提供編輯、變更狀態與刪除入口。恢復進行會更新時間，因此能進入繼續上次。
正式儲存成功後顯示成功訊息；POST 成功後 303 轉址，重新整理不重複提交。

## 資料模型
saves：id（正整數自增）、title、category、status、progress、next_step、memo、created_at、updated_at、version。
category 固定 game / reading / creative / study / other；status 固定 active / paused / completed。
title 必填最多 100 個 Unicode 字元；progress 必填最多 2000；next_step 選填最多 2000；memo 選填最多 4000。
去除首尾空白後檢查必填；中文、日文、emoji 使用 utf8mb4 保存。
時間儲存 UTC，顯示時使用可設定時區，預設 Asia/Tokyo。id 不作為連續的存檔總數，刪除後允許跳號。
version 為正整數，用於阻止舊分頁覆蓋較新修改。

## 表單與錯誤
使用原生 HTML required、maxlength 與 PHP 伺服器端檢查；未知欄位值、陣列代替文字、非法編號不能通過。
檢查失敗回傳 422，保留本次送出的內容並在欄位旁說明錯誤；這不是草稿保存。
修改衝突回傳 409，保留送出的文字、提示重新確認最新版本；不存在的活動回傳 404。
所有寫入均為 POST 並檢查 CSRF；以提交識別碼避免同一次新增被重複送出。
SQL 使用 PDO 參數，HTML 輸出轉義；錯誤畫面不顯示資料庫密碼或堆疊。
連線或寫入失敗不顯示成功，保留本次送出的欄位供重試。

## 驗收
- 空資料庫可新增中文、日文與 emoji；關閉並重新啟動網站／資料庫後仍可讀取。

- PHP 語法檢查、資料庫整合測試與實際瀏覽器操作通過，獨立審查後保存 Commit。
