HOW TO RESTART

讓日常的繼續，更輕鬆一點。

照自己的步調，存檔，然後再次出發。

01

為冒險取個名字

遊戲、閱讀、畫畫、學習，日常的任何事情都可以有存檔點。

02

休息前，先存個檔

目前的進度、下一步，以及不想忘記的事，留下幾句簡短的筆記吧。

03

想繼續時，隨時回來

隔了一段時間也沒關係，之前留下的筆記會告訴你如何繼續。

ABOUT THIS PREVIEW

現在可以體驗的功能

這是以 HTML 和 CSS 製作的畫面原型，顯示的記錄皆為示範資料。

  • 查看全部、進行中、暫停中與已完成的示範存檔
  • 依分類篩選，開啟示範存檔的「繼續查看」頁面
  • 在新增與編輯表單中試填內容
  • 在手機上查看對應的版面
  • 從最近存檔繼續查看，並預覽尚無存檔時的畫面 — 查看首次使用畫面

儲存、更新、刪除與帳號功能將於之後加入。離開頁面或切換語言時，試填的內容可能會消失。
